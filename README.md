# tribepeer (Go)

Server client for TribePeer — e-campus, organisation training, e-library, and AI-powered learning.

**Setup, keys, and first request:** see the [root README](../README.md).

```bash
go get tribepeer@v0.1.0
```

From this repo, until the module is published:

```bash
go mod edit -replace tribepeer=./go
```

Get keys: [tribepeer.com/tribe-owner/credentials](https://www.tribepeer.com/tribe-owner/credentials)  
API guide: [tribepeer.com/institutions/docs](https://www.tribepeer.com/institutions/docs)

The client secret stays on your server.
